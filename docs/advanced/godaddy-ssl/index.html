Godaddy 域名证书配置

核心说明： Godaddy 域名证书配置用于将自定义域名绑定到系统，并通过 SSL 证书启用 HTTPS 安全访问，确保顾客访问网站时更加安全可靠。

功能说明​

  • 域名绑定：支持将已购买的自定义域名绑定到系统网站。

  • DNS 配置：支持通过CNAME 记录方式完成域名解析。

  • SSL 安全：支持上传 SSL 证书，实现 HTTPS 安全访问。

  • 统一管理：所有域名、DNS 记录及证书信息集中在 Godaddy 后台统一维护。

系统字段说明​

  • 域名：用户购买并需要绑定到系统的自定义网址，例如 example.com。

  • A 记录：将域名直接指向服务器 IP 地址的 DNS 配置方式。

  • CNAME 记录：将子域名指向另一个域名的 DNS 配置方式。

  • SSL 证书：用于启用 HTTPS 安全访问的加密证书文件。

  • DNS 生效时间：域名解析更新后，通常需要数分钟至数小时才会完全生效。

操作路径： Godaddy → 域名 → DNS 管理 → SSL 证书

操作步骤​

1. 购买域名2. 进入 DNS 管理3. 配置域名解析4. 导入 DNS 记录5. 配置 SSL 证书6. 检查域名状态

1. 搜索和注册GODADDY账户​

1. 搜索和注册GODADDY账户

在Google浏览器中搜索 Godaddy 的网址www.godaddy.com。点击Sign In再选择Create an Account创建新账户。

图 1：创建godaddy用户

2. 购买域名和SSL证书​

1. 添加域名到购物车

登录 Godaddy 后，搜索需要使用的域名并添加到购物车。可根据需求选择不同后缀，例如 .com、.ca、.net 等。

图 2：搜索域名

图 3：域名添加购物车

2. 添加证书到购物车

点击左上角Godaddy标识回到Godaddy首页，点击Security再选择SSL Certificates进入证书类型选择页面。

图 4：搜索证书

在SSL Certificates页面，选择“Single Domain DV SSL”再点击Add to Cart把证书添加进购物车。

图 5：证书添加购物车

Select number of domains to protect默认选择“Protect 1 Website”

Select term length根据自身计划选择对应的时长。

图 6：证书选项

Recommended - We'll install your SSL Certificatet默认选择“No thanks, I'll install and configure the SSL myself.”，然后点击Continue。

图 7：添加购物车项

3. 支付和购买

后续直接在购物车中绑定信用卡进行结账付款即可以购买成功。

3. 域名配置解析​

3. 域名配置解析

首页点击右上角 账户名称 点击 My Products 进入控制台页面。

图 7：进入控制台

在控制台页面点击右上角 账户名称 点击 My Products 进入我的产品页面。

图 8：进入我的产品

在我的产品页面点击 Domains 下的 DNS 按钮进入 DNS Management 页面。

图 9：进入DNS管理

在 DNS 管理页面，选择DNS 记录找到CNAME类型，WWW名称的记录点击后面的编辑按钮。如果没有此条内容，需要新增一条CNAME类型，WWW名称的记录继续下一步操作。

图 10：修改DNS

在内容值内填入 alb-tfjjjymtxlxmzkk0lh.us-west-1.alb.aliyuncsslbintl.com ，TTL栏位选择自定义输入600，然后保存。

图 11：修改内容值和TTL

之后设置转址，在 DNS Management 页面点击 Forwarding 点击 Add Forwarding 按钮

图 12：添加转址

之后设置转址，在 DNS Management 页面点击 Forwarding 点击 Add Forwarding 按钮

图 13：修改内容值和TTL

保存后，系统会开始同步 DNS 配置。

4. 导入 DNS 记录

如果已有现成的 DNS 配置，可使用批量导入方式快速完成设置。

支持将 JSON 或 Excel 格式的数据转换为 Godaddy 可识别的 DNS 记录内容后导入。

导入完成后，请再次确认记录内容是否正确，避免影响网站访问。

5. 配置 SSL 证书

在 SSL 设置页面中，点击 安装证书 或 上传证书。

上传系统提供的证书文件及私钥文件，完成 SSL 配置。

保存后，系统会自动启用 HTTPS 加密访问。

6. 检查域名状态

返回 Godaddy 域名列表页面，可查看当前域名是否已经成功启用 DNS 解析及 SSL 状态。

当域名状态显示正常且浏览器可通过 HTTPS 打开时，说明配置已经完成。

温馨提示​

注意 1： DNS 配置修改后不会立即生效，通常需要等待几分钟到 24 小时不等。

注意 2： 如果域名同时存在多个 A 记录或 CNAME 记录，可能会导致访问异常，请确认记录内容是否重复。

注意 3： SSL 证书上传后，如果浏览器仍提示不安全，可尝试等待证书同步完成后再访问。

注意 4： 修改 DNS 前建议先备份现有记录，避免误删后导致网站无法访问。

注意 5： 如果网站已绑定其他 CDN、Cloudflare 或第三方 DNS 服务，请先确认当前域名的 NS 指向是否正确。
