积分规则

核心说明： 积分规则用于设定会员积分的获取、消耗及有效期规则，是会员体系的重要组成部分。

功能说明​

  • 积分获取：支持消费、推荐、新增客户等多种积分来源设置。
  • 积分消耗：支持按比例抵扣金额（如 1 元 = 10 积分）。
  • 有效期控制：可设置积分有效期，提升客户复购率。
  • 规则联动：支持与项目、产品、权益等模块联动设置。

积分机制说明​

  • 积分获取：通过消费、推荐、注册等行为获得积分。
  • 积分消耗：积分可用于抵扣消费金额。
  • 积分有效期：每笔积分可设置独立有效时间。
  • 积分展示：客户可在 App 中查看积分及规则说明。

操作路径： 设置 → 更多 → 积分规则

温馨提示​

注意 1： 积分规则保存后，仅对新产生的业务生效，不会自动影响历史订单或历史积分。

注意 2： 如果项目、产品或权益单独设置了积分规则，则会优先生效，系统总规则不会覆盖单独规则。

注意 3： 仅已激活会员状态的客户才可正常获得积分。

注意 4： 客户端展示的积分规则说明需手动开启，否则客户无法在 App 中查看。

积分规则说明​

  • 新增客户获得积分：新添加客户信息后可自动获得积分。

  • 启用产品 / 项目 / 权益积分规则： 若单独设置积分规则，则会优先生效。



    • 项目路径：设置 → 基础设置 → 项目管理 → 编辑项目 → 积分获取规则



    • 产品路径：设置 → 基础设置 → 产品管理 → 编辑产品 → 积分获取规则



    • 权益路径：设置 → 权益设置 → 会员权益 → 编辑客户权益 → 积分获取规则



    • “代金券 / 套餐 / 礼品卡”规则与权益类似。

  • 仅已激活会员积分： 仅开启会员状态的客户才可获得积分。


  • 客户消费获得积分：消费项目或产品后可获得积分。
  • 客户办理权益获得积分：购买权益类产品后可获得积分。
  • 推荐人消费奖励：被推荐客户消费时，推荐人可获得积分。
  • 推荐人办理奖励：被推荐客户购买权益时，推荐人可获得积分。
  • 推荐人邀请奖励：邀请客户注册成功后，推荐人可获得积分。
  • 被推荐人奖励：新客户注册成功后可获得积分。
  • 新建客户奖励：所有注册客户均可获得积分。
