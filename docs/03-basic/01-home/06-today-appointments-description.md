# 今日预约

<div className="doc-tip-box">
  <strong>核心说明：</strong>
  今日预约用于展示当天尚未开单的预约记录，并支持快速进入收银操作。
</div>

## 功能说明

<div className="step-block">

  <div className="step-desc">
    今日预约模块用于展示当天未完成开单的预约信息，并按时间顺序进行排序。
  </div>

  <ul className="key-list compact-list">
    <li>首页里的今日预约一栏，展示今日还没有开单的预约，顺序根据临近时间排序</li>
    <li>可点击对应预约后的 <strong>“开单”</strong> 按钮，跳转至收银页面完成收款</li>
  </ul>

  <div style={{ marginTop: '12px', fontSize: '14px', color: '#666' }}>
    <strong>操作路径：</strong> 系统后台 → 首页 → 今日预约
  </div>

</div>
